01 / Challenge

Make creative production accessible.

A classroom design tool should let a learner progress from a blank canvas to a real printed product without requiring complex publishing software. Button Studio brings design, artwork selection and print preparation together in a browser workspace.

02 / Selected software

Button Studio — general edition.

The independent, unbranded edition provides editable templates, artwork selection, image uploads, layer controls, undo and redo, editable project export, and actual-size printable PDFs. It is installable as a progressive web app.

03 / Design decisions

Support the entire workflow.

01Start with a template

Reduce setup and let users focus on the visual design.

02Iterate without losing work

Layer controls, undo and redo, local saves and project export support revision.

03Produce a usable artifact

Actual-size PDF output connects the digital design to a physical product.

The general edition deliberately excludes team and school branding. Its documented asset catalog records artwork provenance, and uploaded images are processed locally in the browser.

04 / Release evidence

A completed build, with clear boundaries.

The standalone repository records successful validation and deployment workflows on November 3, 2026. This case study describes that completed build; the wider classroom project directory continues to mark applications as in development and seeking feedback.

Scope: Successful repository checks establish build and deployment evidence, not independent verification of every live feature or student learning gains. Other classroom apps are omitted from this curated portfolio pending completion review.
