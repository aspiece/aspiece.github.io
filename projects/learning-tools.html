Selected work / Classroom & Learning Tools

Educational software · Programming practice · Creative production

Build tools that make learning more practical.

Three selected educational software projects demonstrate how instructional needs become practical tools: a browser-based Python workspace, a guided VS Code extension and a standalone design-to-print application.

01 / Challenge

Remove friction between learning and doing.

Beginning programmers need a manageable environment for writing, tracing and testing code, along with guidance that helps them start without giving away the solution. Creative learners likewise need a straightforward path from an idea to a physical product. These tools address those distinct needs.

02 / Programming practice

Scaffold the next action, not the answer.

Browser-based workspace

Python Lab

Write, run, debug and test Python without installing a local development environment. The workspace provides multiple files, a simulated terminal, general starter examples, local project storage and a variable-by-variable trace table.

VS Code / GitHub Codespaces

CS50 Learning Companion

Supports Harvard CS50P coursework with 41 unsolved starter assignments, incremental hints, Python references, testing and submission shortcuts. Official problem requirements remain authoritative, and students complete the logic themselves.

Explore the extension ↗
01Make reasoning visible

Python Lab's trace table supports prediction, execution and examination of variable changes.

02Preserve independence

The Companion adjusts starter scaffolding across problem sets, retaining required signatures and leaving the solution to the learner.

03Protect learner work

Python Lab stores projects in the current browser profile and supports export. The Companion preserves existing assignment Python files during updates.

Python Lab offers general practice examples; CS50P-specific assignment starters are provided by the separate Companion. Both projects support learning without replacing official coursework or student reasoning.

03 / Creative production

Button Studio: general edition.

The independent, unbranded edition provides editable templates, artwork selection, image uploads, layer controls, undo and redo, editable project export, and actual-size printable PDFs. It is installable as a progressive web app.

04 / Design decisions

Support the entire workflow.

01Start with a template

Reduce setup and let users focus on the visual design.

02Iterate without losing work

Layer controls, undo and redo, local saves and project export support revision.

03Produce a usable artifact

Actual-size PDF output connects the digital design to a physical product.

The general edition deliberately excludes team and school branding. Its documented asset catalog records artwork provenance, and uploaded images are processed locally in the browser.

05 / Release evidence

Documented builds, with clear boundaries.

Button Studio's standalone repository records successful validation and deployment workflows on November 3, 2026. Python Lab is publicly deployed; the most recent smoke-test runs reviewed on November 19, 2026 did not pass. CS50 Learning Companion's v0.9.9 prerelease was published on November 18, 2026 following a successful build workflow. The programming tools are included as implemented, evolving classroom projects, not as fully validated final releases.

Scope: Repository checks establish build and deployment evidence, not independent verification of every live feature or student learning gains. No improvement in learning outcomes is claimed. Other classroom apps are omitted from this curated portfolio pending completion review.
